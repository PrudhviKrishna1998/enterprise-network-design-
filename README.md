# Enterprise Network Design & Migration

Designed a scalable enterprise network architecture for a four-campus educational institution as part of a team project.

### Key Highlights
- Designed hierarchical network architecture using Core, Distribution, and Access layers
- Implemented VLAN segmentation, subnetting, and IP addressing plans
- Planned secure inter-campus connectivity, firewall protection, and remote access
- Designed scalable infrastructure supporting 20% annual growth
- Proposed network upgrades including routers, switches, wireless access points, and UPS systems

### Technologies & Concepts
- VLANs
- OSPF
- ACLs
- NAT
- DHCP
- VPN
- IP Addressing & Subnetting
